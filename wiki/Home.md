## 核心功能

### 预算管理
- 年度预算编制
- OPEX/CAPEX 分类
- 版本控制
- 预算调整

### 采购申请
- 在线申请提交
- 预算余额检查
- 多级审批流程
- 执行跟踪

### 审批工作流
- 可视化审批流程
- 实时通知推送
- 审批历史记录
- 权限控制

### 报表分析
- 多维度汇总
- 趋势分析
- 预算预警
- 数据导出

## 技术栈

| 层次 | 技术 | 版本 |
|-----|------|------|
| 后端框架 | Django | 4.2+ |
| API 框架 | Django REST Framework | 3.14+ |
| 前端框架 | Vue 3 | 3.4+ |
| UI 组件库 | Element Plus | 2.5+ |
| 状态管理 | Pinia | 2.1+ |
| 数据库 | MySQL | 8.0+ |
| 缓存 | Redis | 7.0+ |
| 部署 | Docker | 20.10+ |

```

│   ├── apps/            # 业务应用

├── frontend/            # Vue3 前端
│   ├── src/
│   │   ├── api/        # API 接口
```
