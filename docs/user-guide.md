## 系统登录

### 访问系统

打开浏览器，访问系统地址：`http://localhost`

### 登录账号

输入用户名和密码：
- 用户名：`admin`
- 密码：`admin123`

点击【登录】按钮进入系统。

### 忘记密码

请联系系统管理员重置密码。

## 仪表盘

登录后默认进入仪表盘页面，展示系统核心数据概览。

### 统计卡片

顶部四个统计卡片显示：
- **预算总额**：当前年度所有预算的总金额
- **已使用金额**：已审批通过的预算使用金额
- **待审批事项**：等待您审批的申请数量
- **本月新增**：本月新增的预算和申请数量

### 快捷操作

左侧快捷操作区域提供快速入口：
- **创建预算**：快速创建新的预算
- **创建采购申请**：快速创建采购申请
- **审批中心**：查看待审批事项
- **报表分析**：查看数据报表

### 预算使用率

显示当前预算的使用百分比，包括：
- 已使用金额
- 总预算金额
- 使用率进度条

### 最近待审批

显示最近需要您审批的申请列表，包括：
- 申请类型（预算/采购）
- 申请编号和名称
- 申请金额
- 发起时间
- 操作按钮

### 预算预警

显示使用率超过 80% 的预算列表，包括：
- 预算编号和名称
- 使用率百分比
- 剩余可用金额

### 月度趋势

展示预算和使用的月度趋势图表。

## 部门管理

### 查看部门列表

点击左侧菜单【部门管理】进入部门列表页面。

部门以树形结构展示，支持：
- 展开/折叠子部门
- 查看部门详情
- 搜索部门

### 创建部门

1. 点击【新建部门】按钮
2. 填写部门信息：
   - 部门名称
   - 部门编码
   - 上级部门
   - 部门负责人
   - 预算管理员
3. 点击【保存】

### 编辑部门

1. 在部门列表中找到目标部门
2. 点击【编辑】按钮
3. 修改部门信息
4. 点击【保存】

### 删除部门

1. 在部门列表中找到目标部门
2. 点击【删除】按钮
3. 确认删除

> **注意**：删除部门会同时删除其所有子部门，请谨慎操作。

## 预算管理

### 查看预算列表

点击左侧菜单【预算管理】进入预算列表页面。

支持筛选条件：
- 预算年度
- 部门
- 预算类别（OPEX/CAPEX）
- 状态

### 创建预算

#### 基础信息

1. 点击【新建预算】按钮
2. 填写基础信息：
   - 预算年度
   - 所属部门
   - 预算类别（OPEX/CAPEX）
   - 预算名称
   - 预算说明

#### 预算明细

添加预算明细项：
- 项目名称
- 规格型号
- 数量
- 单价
- 月份分布
- 关联项目

系统会自动计算：
- 单项总价 = 数量 × 单价
- 预算总额 = 所有明细项总和

3. 点击【保存草稿】或【提交审批】

### 编辑预算

**草稿状态**的预算可以编辑：
1. 在预算列表中找到目标预算
2. 点击【编辑】按钮
3. 修改预算信息
4. 点击【保存】

### 提交审批

1. 在预算列表中找到草稿状态的预算
2. 点击【提交审批】按钮
3. 确认提交

提交后预算状态变为【待审批】，将进入审批流程。

### 查看预算详情

点击预算列表中的预算编号，查看详细信息：
- 基础信息
- 预算明细
- 审批历史
- 执行记录

### 预算调整

对于已批准的预算，可以申请调整：
1. 在预算详情页点击【申请调整】
2. 选择调整类型（增加/减少）
3. 填写调整金额和原因
4. 提交审批

## 采购申请

### 查看申请列表

点击左侧菜单【采购申请】进入申请列表页面。

支持筛选条件：
- 申请状态
- 申请日期
- 关联预算

### 创建采购申请

#### 选择预算

1. 点击【新建申请】按钮
2. 选择关联的预算（系统会显示可用余额）
3. 填写申请信息：
   - 申请标题
   - 申请理由

#### 添加采购物品

添加需要采购的物品：
- 物品名称
- 规格型号
- 数量
- 预估单价

系统会自动：
- 计算单项总价
- 计算申请总额
- 检查是否超出预算可用余额

4. 点击【保存草稿】或【提交审批】

### 编辑申请

**草稿状态**的申请可以编辑：
1. 在申请列表中找到目标申请
2. 点击【编辑】按钮
3. 修改申请信息
4. 点击【保存】

### 提交审批

1. 在申请列表中找到草稿状态的申请
2. 点击【提交审批】按钮
3. 确认提交

提交后申请状态变为【待审批】，预算金额将被【占用】。

### 查看申请详情

点击申请列表中的申请编号，查看详细信息：
- 基础信息
- 采购物品清单
- 审批进度
- 审批历史

## 审批中心

### 待审批列表

点击左侧菜单【审批中心】进入审批页面。

默认显示【待我审批】的列表，包括：
- 预算审批
- 采购申请审批

### 处理审批

1. 在待审批列表中找到目标申请
2. 点击【处理】按钮
3. 查看申请详情
4. 填写审批意见
5. 选择【通过】或【驳回】

### 审批流程

系统支持多级审批流程：
```
提交 → 部门负责人 → 预算管理员 → 财务 → 采购部 → 完成
```

每个审批节点都可以：
- 通过：进入下一审批节点
- 驳回：退回给申请人

### 审批历史

在申请详情页可以查看完整的审批历史：
- 审批人
- 审批时间
- 审批结果
- 审批意见

### 已审批记录

切换至【我已审批】标签，查看您已处理的审批记录。

## 报表分析

### 预算汇总

点击左侧菜单【报表分析】进入报表页面。

预算汇总展示：
- 总预算金额
- 已使用金额
- 已占用金额
- 可用余额
- 使用率

支持维度筛选：
- 按部门汇总
- 按类别汇总（OPEX/CAPEX）
- 按月度汇总

### 预算执行明细

查看每笔预算的执行详情：
- 预算基本信息
- 已使用金额明细
- 关联的采购申请

### 趋势分析

展示预算和使用的趋势图表：
- 月度趋势对比
- 部门对比分析
- 类别占比分析

### 数据导出

支持导出报表数据：
1. 选择筛选条件
2. 点击【导出】按钮
3. 选择导出格式（Excel/PDF）
4. 下载文件

## 个人设置

### 修改个人信息

1. 点击右上角用户名
2. 选择【个人设置】
3. 修改个人信息：
   - 真实姓名
   - 邮箱
   - 手机号
4. 点击【保存修改】

### 修改头像

1. 在个人设置页面，点击头像区域
2. 选择图片文件（支持 jpg、png、gif，最大 2MB）
3. 系统自动上传并更新头像

### 修改密码

1. 在个人设置页面，找到【修改密码】区域
2. 填写：
   - 旧密码
   - 新密码（至少8位）
   - 确认新密码
3. 点击【修改密码】

> **注意**：修改密码后需要重新登录。

## 常见问题

### Q: 为什么无法提交预算审批？

A: 请检查：
- 预算是否已填写明细
- 预算总额是否大于0
- 是否已选择所属部门

### Q: 采购申请提交后预算余额没有变化？

A: 采购申请提交后，预算金额会被【占用】，但不会立即扣减。待审批通过后才会正式扣减。

### Q: 如何查看审批进度？

A: 在预算或采购申请详情页，可以查看完整的审批历史和当前审批节点。

### Q: 审批被驳回了怎么办？

A: 根据审批意见修改申请内容后，可以重新提交审批。

### Q: 系统支持哪些浏览器？

A: 推荐使用 Chrome、Firefox、Edge 等现代浏览器，IE 浏览器不支持。
