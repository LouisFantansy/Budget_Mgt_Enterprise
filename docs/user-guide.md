## 1. 系统登录

### 1.1 访问系统

在浏览器地址栏输入系统地址：
- 开发环境：`http://localhost:5173`
- 生产环境：`https://your-domain.com`

### 1.2 默认账号

系统初始化后提供以下默认账号：

| 账号 | 密码 | 角色 | 用途 |
|-----|------|-----|------|
| admin | admin123 | 系统管理员 | 系统管理、用户管理 |
| budget_manager | bm123 | 预算管理员 | 预算审核、全局监控 |
| dept_head | dh123 | 部门负责人 | 部门预算管理、审批 |
| finance | fin123 | 财务人员 | 财务审批、报表查看 |
| purchaser | pur123 | 采购员 | 提交采购申请 |
| viewer | view123 | 普通用户 | 查看本部门数据 |

### 1.3 登录步骤

1. 打开系统登录页面
2. 输入用户名和密码
3. 点击"登录"按钮
4. 登录成功后自动跳转到仪表盘

### 1.4 修改密码

1. 点击右上角用户头像
2. 选择"修改密码"
3. 输入旧密码和新密码
4. 点击"确认修改"

> **注意：** 首次登录后建议立即修改默认密码

## 2. 仪表盘使用

### 2.1 仪表盘概览

登录后默认进入仪表盘页面，展示以下关键指标：

| 指标卡片 | 说明 |
|---------|------|
| 总预算金额 | 本年度所有预算总额 |
| 已使用金额 | 已审批通过的采购金额 |
| 剩余预算 | 总预算 - 已使用 - 冻结 |
| 预算执行率 | 已使用金额 / 总预算金额 |
| 待审批数量 | 当前用户待处理的审批事项 |
| 本月采购金额 | 本月已批准的采购金额 |

### 2.2 图表展示

- **预算使用趋势**：按月展示预算使用情况
- **部门预算分布**：各部门预算占比饼图
- **预算类型分布**：OPEX/CAPEX占比

### 2.3 快捷操作

仪表盘提供以下快捷入口：
- 新建预算
- 新建采购申请
- 查看待审批
- 查看预算汇总

## 3. 预算管理操作

### 3.1 查看预算列表

1. 点击左侧菜单"预算管理" → "预算列表"
2. 列表展示以下信息：
   - 预算编号
   - 预算名称
   - 所属部门
   - 预算类型（OPEX/CAPEX）
   - 年度
   - 总金额
   - 已使用金额
   - 状态

### 3.2 筛选预算

使用列表上方的筛选条件：
- **部门**：选择特定部门
- **年度**：选择预算年度
- **类型**：OPEX / CAPEX / 全部
- **状态**：草稿 / 待审批 / 已审批 / 已拒绝 / 已调整
- **关键词**：搜索预算名称或编号

### 3.3 创建预算

#### 3.3.1 快速创建

1. 点击"新建预算"按钮
2. 填写基本信息：
   - 预算名称（必填）
   - 所属部门（必填）
   - 预算类型（必填）：选择 OPEX 或 CAPEX
   - 年度（必填）
3. 添加预算明细：
   - 点击"添加项目"
   - 填写项目名称、费用类别、单价、数量
   - 系统自动计算合计金额
4. 点击"保存为草稿"或"提交审批"

#### 3.3.2 高级创建

1. 点击"高级创建"
2. 支持更多字段：
   - 规格型号
   - 功能描述
   - 月度计划（按月分配预算）
   - 所属项目
   - 用途说明
   - 供应商
   - 交付日期

### 3.4 编辑预算

> **注意：** 仅"草稿"状态的预算可以编辑

1. 在预算列表中找到目标预算
2. 点击"编辑"按钮
3. 修改相关信息
4. 点击"保存"

### 3.5 提交审批

1. 在预算列表中找到草稿状态的预算
2. 点击"提交审批"按钮
3. 确认提交
4. 系统根据金额自动确定审批级别：
   - < 5万：2级审批（部门负责人 → 预算管理员）
   - 5-50万：3级审批（+ 总监）
   - ≥ 50万：4级审批（+ 总经理）

### 3.6 查看预算详情

1. 点击预算列表中的预算名称
2. 查看详细信息：
   - 基本信息
   - 预算明细列表
   - 审批流程进度
   - 关联的采购申请
   - 预算使用记录

### 3.7 预算调整

> **注意：** 仅"已审批"状态的预算可以调整

1. 进入预算详情页
2. 点击"调整预算"按钮
3. 修改预算金额或明细
4. 填写调整原因
5. 提交调整申请（需重新审批）

### 3.8 删除预算

> **注意：** 仅"草稿"状态的预算可以删除

1. 在预算列表中找到目标预算
2. 点击"删除"按钮
3. 确认删除

### 3.9 预算汇总

1. 点击左侧菜单"预算管理" → "预算汇总"
2. 查看多维度汇总：
   - 按部门汇总
   - 按类型汇总（OPEX/CAPEX）
   - 按年度汇总
3. 点击汇总数据可下钻查看明细

### 3.10 预算使用追踪

1. 点击左侧菜单"预算管理" → "使用追踪"
2. 选择要追踪的预算
3. 查看使用情况：
   - 预算总额
   - 已使用金额
   - 冻结金额（审批中占用）
   - 可用余额
   - 使用率百分比
4. 查看使用记录列表

## 4. 采购申请操作

### 4.1 查看采购申请列表

1. 点击左侧菜单"采购管理" → "采购申请"
2. 列表展示以下信息：
   - 申请编号
   - 申请日期
   - 申请人
   - 所属部门
   - 关联预算
   - 总金额
   - 紧急程度
   - 状态

### 4.2 创建采购申请

1. 点击"新建采购申请"按钮
2. 选择关联预算（必填）
3. 系统显示该预算的可用余额
4. 填写采购明细：
   - 物品名称
   - 规格型号
   - 数量
   - 单价
   - 供应商（可选）
   - 交付日期（可选）
   - 备注（可选）
5. 填写用途说明
6. 选择紧急程度（低/普通/高/紧急）
7. 上传附件（可选，支持多文件）
8. 点击"保存为草稿"或"提交审批"

> **注意：** 提交时会检查预算可用余额，余额不足无法提交

### 4.3 编辑采购申请

> **注意：** 仅"草稿"或"已拒绝"状态的申请可以编辑

1. 在列表中找到目标申请
2. 点击"编辑"按钮
3. 修改相关信息
4. 点击"保存"

### 4.4 提交采购审批

1. 在列表中找到草稿状态的申请
2. 点击"提交审批"按钮
3. 确认提交
4. 提交后相应预算额度被冻结

### 4.5 查看采购申请详情

1. 点击申请列表中的申请编号
2. 查看详细信息：
   - 基本信息
   - 采购明细
   - 审批流程进度
   - 附件列表
   - 审批历史

### 4.6 删除采购申请

> **注意：** 仅"草稿"或"已拒绝"状态的申请可以删除

1. 在列表中找到目标申请
2. 点击"删除"按钮
3. 确认删除

## 5. 审批操作

### 5.1 查看待审批列表

1. 点击左侧菜单"审批中心"
2. 默认显示"待我审批"标签页
3. 列表展示：
   - 审批类型（预算/采购）
   - 申请人
   - 申请部门
   - 金额
   - 当前审批步骤
   - 提交时间

### 5.2 查看审批详情

1. 点击待审批列表中的记录
2. 查看完整信息：
   - 申请详情
   - 审批流程图
   - 历史审批意见
3. 在页面底部进行审批操作

### 5.3 通过审批

1. 进入审批详情页
2. 填写审批意见（可选）
3. 点击"通过"按钮
4. 确认通过
5. 审批通过后：
   - 如有下一步，流转到下一审批人
   - 如为最后一步，申请状态变为"已批准"
   - 采购申请批准后，冻结金额转为已使用

### 5.4 拒绝审批

1. 进入审批详情页
2. 填写拒绝原因（必填）
3. 点击"拒绝"按钮
4. 确认拒绝
5. 拒绝后：
   - 申请状态变为"已拒绝"
   - 采购申请拒绝后，释放冻结的预算额度

### 5.5 撤回申请

> **注意：** 仅申请人可操作，且审批未完成时

1. 进入"我发起的"标签页
2. 找到目标申请
3. 点击"撤回"按钮
4. 填写撤回原因
5. 确认撤回
6. 撤回后：
   - 申请状态变为"已撤回"
   - 释放冻结的预算额度
   - 可重新编辑后提交

### 5.6 查看我发起的审批

1. 在审批中心点击"我发起的"标签页
2. 查看所有本人提交的申请
3. 可查看每个申请的当前状态

## 6. 数据导入导出

### 6.1 导出预算报表

1. 进入"预算列表"页面
2. 设置筛选条件（可选）
3. 点击"导出"按钮
4. 选择导出格式（Excel）
5. 系统自动下载报表文件

### 6.2 导出采购报表

1. 进入"采购申请"页面
2. 设置筛选条件（可选）
3. 点击"导出"按钮
4. 系统自动下载报表文件

### 6.3 下载导入模板

1. 进入"数据导入" → "采购订单导入"
2. 点击"下载模板"按钮
3. 根据模板格式准备数据

### 6.4 导入采购订单

1. 进入"数据导入" → "采购订单导入"
2. 点击"选择文件"按钮
3. 选择准备好的Excel文件
4. 点击"开始导入"
5. 查看导入结果：
   - 成功导入数量
   - 失败记录及原因

### 6.5 导入结算单

操作步骤同"导入采购订单"

### 6.6 三单匹配

#### 6.6.1 自动匹配

1. 进入"数据导入" → "三单匹配"
2. 点击"执行自动匹配"按钮
3. 系统根据预算编号自动关联采购订单和结算单
4. 查看匹配结果

#### 6.6.2 手动关联

1. 在三单匹配列表中找到未匹配的记录
2. 点击"手动关联"按钮
3. 选择对应的预算单、采购订单、结算单
4. 点击"确认关联"

#### 6.6.3 匹配状态说明

| 状态 | 说明 |
|-----|------|
| 完全匹配 | 三单金额一致，自动关联成功 |
| 部分匹配 | 金额有差异，需人工确认 |
| 未匹配 | 无法找到对应单据 |

## 7. 通知管理

### 7.1 查看通知

1. 点击顶部导航栏的铃铛图标
2. 展开通知列表
3. 未读通知显示红点标记

### 7.2 通知类型

| 类型 | 说明 | 接收人 |
|-----|------|-------|
| 待审批提醒 | 有新的审批任务 | 审批人 |
| 审批结果通知 | 申请被批准/拒绝 | 申请人 |
| 预算预警 | 预算使用率超过80% | 预算管理员、部门负责人 |
| 预算超支警告 | 预算已超支 | 预算管理员、部门负责人 |
| 系统公告 | 系统维护等通知 | 所有用户 |

### 7.3 标记已读

1. 点击通知列表中的通知，自动标记为已读
2. 或点击"全部已读"按钮，标记所有通知为已读

### 7.4 通知设置

1. 点击"设置" → "通知设置"
2. 配置接收渠道：
   - 站内通知
   - 邮件通知
3. 配置接收类型

## 9. 常用操作快速指南

### 9.1 预算编制流程

```
创建预算 → 添加明细 → 保存草稿 → 提交审批 → 等待审批 → 审批通过 → 预算生效
```

### 9.2 采购申请流程

```
选择预算 → 填写申请 → 添加物品 → 提交审批 → 逐级审批 → 审批通过 → 执行采购
```

### 9.3 预算调整流程

```
选择已批预算 → 点击调整 → 修改金额 → 填写原因 → 提交审批 → 重新审批 → 调整生效
```

### 9.4 审批处理流程

```
收到通知 → 查看待审批 → 查看详情 → 填写意见 → 通过/拒绝 → 流程推进/结束
```

### 9.5 快捷键列表

| 快捷键 | 功能 |
|-------|------|
| Ctrl + N | 新建（预算/采购申请） |
| Ctrl + S | 保存 |
| Ctrl + Enter | 提交 |
| Esc | 关闭弹窗/返回 |
| / | 聚焦搜索框 |

### 9.6 常见问题 FAQ

**Q: 为什么无法编辑预算？**  
A: 只有"草稿"状态的预算可以编辑。已提交的预算需要撤回后才能编辑。

**Q: 提交采购申请时提示余额不足？**  
A: 请检查关联预算的可用余额（总预算 - 已使用 - 冻结）。如余额不足，需等待其他采购完成或申请预算调整。
