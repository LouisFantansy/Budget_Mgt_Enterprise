## 1. 项目概述

### 1.1 项目目标

为半导体研发企业构建一套完整的研发预算编制与执行管理系统。系统覆盖从预算编制表单模板维护、预算条目编制、多级审批、到实时 Dashboard 监控的全流程管理。系统定位是**研发内部管理工具**，不包含采购和财务模块。

### 1.2 项目范围

**包含范围：**
- 预算编制表单模板管理（字段配置、下拉内容、公式、可见性）
- OPEX/CAPEX 预算编制（含集团分摊和自编）
- Git 模式的预算版本管理
- 多级审批工作流
- 实时 Dashboard 看板（多维度、可配置）
- 专题需求收集表（自定义模板）
- 数据导入导出（Excel）
- 历史采购记录智能补全
- 版本迭代可视化（热力图、拓扑图）
- 审计留痕

**不包含范围：**
- 采购执行系统
- 财务核算系统对接
- 外部供应商管理
- 合同管理
- 资产管理系统

### 1.3 组织架构模型

```
一级部门（SS）
├── 一级部门预算管理员
├── 一级部门预算管理员主办
├── 一级部门负责人
├── SS Public（不分摊，直接挂在一级部门下）
│
├── 二级部门 A
│   ├── 二级部门负责人
│   ├── 主二级部门预算管理员（可触发送审）
│   ├── 次二级部门预算管理员（不可触发送审）
│   └── 一线工程师（无预算编制权限）
│
├── 二级部门 B
│   ├── 二级部门负责人
│   ├── 主二级部门预算管理员
│   └── 一线工程师
│
└── 二级部门 C
    └── ...
```

## 3. 用户角色定义

### 3.1 角色总览

| 序号 | 角色编码 | 角色名称 | 职责概述 |
|-----|---------|---------|---------|
| 1 | `first_budget_admin` | 一级部门预算管理员 | 维护表单模板、触发编制任务、上传集团分摊、制作专题收集表、生成一级总表 |
| 2 | `first_budget_host` | 一级部门预算管理员主办 | 审核一级部门预算初版，协调预算编制 |
| 3 | `first_dept_head` | 一级部门负责人 | 审批一级部门预算终版 |
| 4 | `second_budget_admin_primary` | 主二级部门预算管理员 | 编制本部门预算、可触发送审、Excel 导入导出、批量修改 |
| 5 | `second_budget_admin_secondary` | 次二级部门预算管理员 | 编制本部门预算、不可触发送审、其他与主预算管理员相同 |
| 6 | `second_dept_head` | 二级部门负责人 | 审批本部门预算、可直接修改任意版本、留痕处理 |
| 7 | `engineer` | 一线工程师 | 无预算编制访问权限 |

### 3.2 角色详细权限

#### 3.2.1 一级部门预算管理员

**预算编制管理：**
- 维护 OPEX/CAPEX 预算编制表单模板
  - 配置哪些字段是下拉选择及下拉内容
  - 配置哪些单元格可填写、不可填写
  - 配置公式（如：总数量=1-12月数量加总，总金额=单价×总数量）
  - 配置字段可见/隐藏
- 触发预算编制任务给各二级部门预算管理员
- **修改所有预算数据（包括二级部门编制的）**
  - 跨部门统一价格调整
  - 统一描述规范化
  - 给每一条预算赋予最终编号
  - **所有修改自动留痕（修改人、时间、前后值）**
- 上传 OPEX 集团分摊数据
- 制作专题需求收集表（自定义表单模板）
- 在所有预算编制表后增加额外列（做标记和说明）
- 一键拉取各部门最新审核版本，生成一级部门完整预算总表
- 配置 Dashboard 展示内容（灵活筛选不同字段生成图表）
- 维护项目字段（项目类别：量产项目、产品项目、TD项目、Pathfinding项目、其他项目）

**数据权限：**
- 查看所有二级部门预算编制数据
- **修改所有二级部门预算编制数据（留痕处理）**
- 查看所有 Dashboard 数据
- 支持下钻到二级部门明细

#### 3.2.2 一级部门预算管理员主办

**预算审核：**
- 审核一级部门预算初版
- 协调各部门预算编制进度
- 提出修改意见

**注意：** 只有最终终版需要一级部门负责人审批。

#### 3.2.3 一级部门负责人

**审批权限：**
- 审批一级部门预算终版
- 查看一级部门 Dashboard 总览

#### 3.2.4 主二级部门预算管理员

**预算编制：**
- 接收一级部门预算编制任务
- 编制本部门 OPEX/CAPEX 预算
- Excel 导入导出预算数据
- 批量修改预算条目
- 触发整个二级部门预算送审
- 随时修订预算（Git 模式），每次修订需送审
- 在预算条目后增加 comment 列（内部管理用，不带入审批）

**数据权限：**
- 查看本部门所有预算数据
- 查看本部门 Dashboard

#### 3.2.5 次二级部门预算管理员

**预算编制：**
- 与主二级部门预算管理员相同的编制权限
- **不可触发预算送审**

#### 3.2.6 二级部门负责人

**审批与修改：**
- 审批本部门预算（每次送审都需审批）
- **可直接修改任意版本的预算**
- 审批通过后的版本，系统做好留痕处理
- 每次审批通过后，版本号自动增加

#### 3.2.7 一线工程师

**权限：**
- **无预算编制访问权限**

## 4. 预算编制表单模板管理

### 4.1 功能概述

一级部门预算管理员负责维护预算编制表单模板，包括字段定义、下拉内容、公式配置、可见性控制等。模板维护完成后，触发预算编制任务给各二级部门预算管理员。

### 4.2 表单字段配置

#### 4.2.1 OPEX 自编预算表单字段

| 序号 | 字段名称 | 字段编码 | 类型 | 可配置项 | 说明 |
|-----|---------|---------|------|---------|------|
| 1 | 预算编号 | budget_no | 文本 | 可见/隐藏 | 系统自动生成 |
| 2 | 预算部门 | dept_name | 下拉 | 下拉内容 | 关联二级部门 |
| 3 | 预算所属 Department | dept_belong | 下拉 | 下拉内容 | 所属部门细分 |
| 4 | 成本中心代码 | cost_center | 文本 | 可见/隐藏/可填 | 成本中心编码 |
| 5 | Category | category | 下拉 | 下拉内容 | 预算分类 |
| 6 | Category L1 | category_l1 | 下拉 | 下拉内容 | 一级分类 |
| 7 | Category L2 | category_l2 | 下拉 | 下拉内容 | 二级分类 |
| 8 | GL Amount | gl_amount | 数值 | 可见/隐藏/公式 | 总账金额 |
| 9 | Project | project | 下拉 | 下拉内容 | 关联项目 |
| 10 | 预算条目描述 | item_desc | 文本 | 可见/隐藏/可填 | 采购内容描述 |
| 11 | 供应商 | supplier | 文本 | 可见/隐藏/可填 | 供应商名称 |
| 12 | 采购原因 | purchase_reason | 文本 | 可见/隐藏/可填 | 采购原因说明 |
| 13 | 总数量 | total_qty | 数值 | **公式** | 自动计算：1-12月数量加总 |
| 14 | 地区 | region | 下拉 | 下拉内容 | 采购地区 |
| 15 | 单价 | unit_price | 数值 | 可见/隐藏/可填 | 预估单价 |
| 16 | 总价 | total_price | 数值 | **公式** | 自动计算：单价×总数量 |
| 17 | 备注 | remark | 文本 | 可见/隐藏/可填 | 备注说明 |
| 18-29 | 1月采购数量 ~ 12月采购数量 | qty_month_1~12 | 数值 | 可见/隐藏/可填 | 月度采购数量 |
| 30-41 | 1月采购金额 ~ 12月采购金额 | amt_month_1~12 | 数值 | **公式/可填** | 月度采购金额 |
| 42+ | 扩展列 | ext_col_n | 多种 | 一级预算管理员可增删 | 额外标记和说明列 |

**公式说明：**
- 总数量 = Σ(1月采购数量 ~ 12月采购数量)
- 总价 = 单价 × 总数量 = Σ(1月采购金额 ~ 12月采购金额)

#### 4.2.2 CAPEX 预算表单字段

CAPEX 表单结构与 OPEX 类似，部分字段有差异：
- 增加资产类别字段
- 增加折旧年限字段
- 增加资产编号字段（系统生成）
- 其他字段与 OPEX 一致

### 4.3 模板配置功能

#### 4.3.1 字段属性配置

每个字段支持配置：
- **可见性**：显示/隐藏
- **可编辑性**：可填写/不可填写（只读）
- **填写方式**：文本输入/下拉选择/公式计算
- **默认值**：可设置默认值
- **必填校验**：是否必填
- **数据格式**：文本/数值/日期等

#### 4.3.2 下拉内容维护

支持下拉选项的动态维护：
- Category 下拉选项
- Category L1/L2 级联下拉
- 项目下拉选项（由一级预算管理员维护）
- 地区下拉选项
- 部门下拉选项（自动同步组织架构）

#### 4.3.3 公式配置

支持配置的公式：
```
总数量 = SUM(qty_month_1, qty_month_2, ..., qty_month_12)
总价 = unit_price × total_qty
总价 = SUM(amt_month_1, amt_month_2, ..., amt_month_12)
```

公式在数据录入时自动计算，用户不可手动修改公式结果。

#### 4.3.4 模板版本管理

- 模板修改后自动保存为新版本
- 已触发编制任务的模板不可随意修改（需确认影响范围）
- 支持模板预览功能

### 4.4 触发预算编制任务

一级部门预算管理员完成模板维护后：
1. 选择预算年度
2. 选择需要编制预算的二级部门
3. 点击【触发预算编制任务】
4. 各二级部门预算管理员收到任务通知
5. 二级部门预算管理员开始编制预算

## 5. OPEX 预算编制

### 5.1 OPEX 预算结构

```
OPEX 总预算
├── 集团分摊（由一级部门预算管理员上传）
└── 自编预算
    ├── 二级部门 A 自编
    ├── 二级部门 B 自编
    ├── 二级部门 C 自编
    └── SS Public（一级部门直接管理，不分摊）
```

### 5.2 OPEX 集团分摊

#### 5.2.1 数据上传

- 由一级部门预算管理员单独上传
- 上传格式：Excel 模板
- 数据内容：集团分摊的预算条目和金额
- 上传后自动计入 OPEX 总预算

#### 5.2.2 数据处理

- 集团分摊数据不参与二级部门审批流程
- 在一级部门预算总表中展示
- 如果集团分摊数据为空，在总表中显示为空

### 5.3 OPEX 自编预算编制流程

#### 5.3.1 编制方式

二级部门预算管理员可通过以下方式编制：
1. **在线录入**：在系统中逐条录入预算条目
2. **Excel 导入**：下载模板，填写后导入
3. **批量修改**：选中多条记录批量修改字段值

#### 5.3.2 预算条目填写

按照一级部门预算管理员维护的表单模板填写：
- 选择/填写各字段内容
- 输入 1-12 月采购数量
- 系统自动计算总数量和总价
- 可在表单后增加 comment 列（内部管理，不带入审批）

#### 5.3.3 智能补全

输入预算条目描述时，支持历史采购记录模糊补全：
- 模糊匹配历史采购记录
- 匹配成功时自动带出推荐单价 = 历史成交价 × 1.2
- 用户可接受建议或自行修改

#### 5.3.4 编制协作

- 主次预算管理员可同时编辑（需考虑并发控制）
- 实时保存草稿（自动保存机制）
- 编制过程中可预览 Dashboard

| 字段 | 说明 |

与 OPEX 自编预算编制流程一致。

## 7. 预算编制流程与版本管理

### 7.1 版本管理模型（Git 模式）

系统采用类似 Git 的版本管理模式：

```
v1.0 (初始版本)
  ├── v1.1 (修订)
  │   ├── v1.2 (修订)
  │   │   └── v2.0 (审批通过，版本号+1)
  │   └── v2.0 (审批通过)
  └── v2.0 (审批通过)
```

#### 7.1.1 版本号规则

- **格式**：`v{major}.{minor}`
- **major**：审批通过后自动 +1
- **minor**：每次修订后 +1
- 示例：v1.0 → v1.1 → v1.2 → v2.0 → v2.1 → v3.0

#### 7.1.2 版本状态

| 状态 | 说明 |
|-----|------|
| 草稿 | 编制中，未送审 |
| 待审批 | 已送审，等待二级部门负责人审批 |
| 审批通过 | 二级部门负责人审批通过，版本号 +1 |
| 审批驳回 | 二级部门负责人驳回，可重新修订 |

### 7.2 编制与审批流程

#### 7.2.1 二级部门预算编制流程

```
┌─────────────────────────────────────────────────────────────────┐
│  一级部门预算管理员触发编制任务                                  │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  二级部门预算管理员接收任务，开始编制                            │
│  - 在线录入 / Excel 导入 / 批量修改                              │
│  - 可随时保存草稿                                               │
│  - 可预览 Dashboard                                             │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  主二级部门预算管理员触发送审                                    │
│  - 系统自动带出前后版本差异                                      │
│  - 生成差异对比报告                                              │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  二级部门负责人审批                                              │
│  - 查看差异对比                                                  │
│  - 可直接修改（留痕处理）                                        │
│  - 通过：版本号 +1                                               │
│  - 驳回：返回修订                                                │
└─────────────────────────────────────────────────────────────────┘
```

#### 7.2.2 版本差异自动对比

每次送审时，系统自动对比当前版本与上一审批通过版本的差异：
- 新增条目（绿色标记）
- 删除条目（红色标记）
- 修改条目（黄色标记，显示旧值→新值）
- 差异汇总统计

#### 7.2.3 二级部门负责人直接修改

二级部门负责人在审批时可直接修改预算内容：
- 系统自动记录修改痕迹（修改人、修改时间、修改前后值）
- 修改后需重新确认审批
- 所有修改记录可追溯

### 7.3 一级部门预算编制流程

#### 7.3.1 一级部门预算总表生成

```
┌─────────────────────────────────────────────────────────────────┐
│  一级部门预算管理员一键拉取                                      │
│  - 抓取各部门当前审核后的最新版本                                 │
```

## 8. 审批流程

### 8.1 审批层级

| 预算类型 | 审批人 | 审批内容 |
|---------|--------|---------|
| 二级部门预算 | 二级部门负责人 | 审核本部门预算编制的合理性和完整性 |
| 一级部门预算初版 | 一级部门预算管理员主办 | 审核数据完整性，提出修改意见 |
| 一级部门预算终版 | 一级部门负责人 | 审批一级部门预算总表终版 |

### 8.2 审批操作

| 操作 | 说明 |
|-----|------|
| 通过 | 审批通过，版本号自动 +1 |
| 驳回 | 驳回申请，返回编制人修订 |
| 直接修改 | 二级部门负责人可直接修改后审批（留痕处理） |

### 8.3 审批通知

- 送审后自动通知审批人
- 审批结果自动通知编制人
- WebSocket 实时推送

## 10. 专题需求收集表

### 10.1 功能概述

为了帮助二级部门精准编制集采及 SS Public 部门的预算，一级部门预算管理员制作专题需求收集表。此类专题表单格式可自定义，随时增加不同类别的收集表，并能和各部门的预算编制表关联。

### 10.2 表单模板自定义

一级部门预算管理员可自定义专题收集表：
- 自由增删字段
- 配置字段类型（文本/数值/下拉/日期等）
- 配置字段可见性（隐藏列功能）
- 配置字段可编辑性

### 10.3 典型专题表单

#### 10.3.1 人力外包需求收集表

| 字段 | 说明 |
|-----|------|
| 外包人员姓名 | 当前在职外包人员 |
| 所属项目 | 挂靠项目信息 |
| 入职时间 | 入职日期 |
| 预计离职时间 | 预计离职日期 |

## 13. 历史采购记录补全

### 13.1 功能概述

二级部门在编制预算的时候，输入预算条目描述时，支持历史采购记录模糊补全。

### 13.2 智能推荐

- 模糊匹配历史采购记录
- 匹配成功时自动带出推荐单价
- 推荐单价 = 历史成交价 × 1.2

### 13.3 用户选择

- 用户可接受推荐单价
- 用户可不接受建议，自行修改单价
- 系统记录用户是否接受推荐

### 13.4 历史数据管理

- 系统自动积累历史采购记录
- 支持历史数据查询
- 支持历史数据维护（管理员）
