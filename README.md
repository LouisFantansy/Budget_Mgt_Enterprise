# Budget Management System

企业级预算管理系统 - Enterprise Budget Management System

## 📋 项目简介

一套功能完整、技术先进的企业级预算管理系统，专为半导体研发企业设计。实现预算管理的全流程自动化和智能化。

## ✨ 核心特性

- 🏢 **部门层级管理**：三级部门树形结构，完整的 CRUD 功能
- 💰 **预算管理**：Opex/Capex分类，版本控制，执行率计算
- 📝 **采购申请**：在线提交，关联预算，五级审批流程
- 📊 **预算监控**：实时占用追踪，智能预警
- 📈 **报表分析**：多维度汇总，数据钻取，可视化图表
- 🎨 **优秀体验**：苹果风格设计，响应式布局

## 🛠️ 技术栈

- **前端框架**: React 18.3.1 + TypeScript 5.x
- **状态管理**: Zustand
- **路由管理**: React Router v6
- **图表库**: Recharts
- **图标**: Lucide React
- **样式**: CSS Variables + 原生 CSS
